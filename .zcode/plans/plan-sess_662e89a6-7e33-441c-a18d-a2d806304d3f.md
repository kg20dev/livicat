## Goal
Rebuild the Phantom flag + ribbon **entirely in CSS** (no SVG), as jagged torn two-tone P5 shapes that are solid, recolorable, and don't distort on long names. Keep the `-13°` tilt and the dynamic contrast flag fill.

## Why abandon SVG
- Baked-in colors can't recolor cleanly; my transparent-fill hack reads as a broken thin outline.
- Fixed SVG proportions distort on variable text.
- The current CSS-flag outline technique (`::before` outset with `z-index:-1`) is the *correct* pattern (crayon uses it) — the earlier reimplementation was right to go CSS, just wrong on the stacking/coordinates. We finish that job properly.

## CEF-109 safety
`clip-path: polygon()` is supported since Chrome 55; CEF-109 is Chromium 109. The file header's constraints (`color-mix()`, `mask-image`, `@import`) are unaffected. Safe.

## The correct two-tone outline technique (reusing the proven sibling pattern)
- Parent = the **outline color** (e.g. black), with the jagged `clip-path`.
- `::before` = the **fill color**, `inset: -2px` is WRONG — instead `::before` is inset *inside* the parent (`top/left/bottom/right` ≈ the outline width), `z-index: -1`, same `clip-path`. Parent establishes a stacking context via `transform: rotate()` + `position: relative`, so the negative-z child correctly layers behind the parent's own painted background → reads as a solid border of the parent color showing around the inset child.
- Fill is a **derived contrast var** (`--flagChipBg`), so the flag recolors opposite to the name text. Per-role `*FlagChipBg` already wired via `strokeMap`.

### Section 2 — NAME FLAG (rewritten, ~#author-name + ::before)
Recolorable jagged flag, tilted `-13°`:
```
.theme-phantom ... #author-name {
  /* outline layer = black; fill is the inset ::before */
  background: var(--p5-black) !important;
  color: var(--usernameColor, var(--p5-black));
  transform: rotate(var(--flag-tilt, -13deg));
  padding: 0.6em 1.6em 0.6em 0.9em;   /* right padding clears the tail */
  clip-path: polygon(
     /* top edge with a notch (zigzag) */
     0 0, 38% 0, 42% 6%, 100% 6%,
     100% 78%,
     /* pointed tail bottom-left */
     0 100%, 14% 78%);
  min-width: 5em; white-space: nowrap; width: fit-content;
}
.theme-phantom ... #author-name::before {
  content:''; position:absolute; inset: 2px; z-index:-1;
  background: var(--flagChipBg, var(--p5-white));   /* derived contrast fill */
  clip-path: <same polygon, inset-adjusted>;
}
```
- Coordinates in `%` for the body width and small `em`/`%` for the notch+tail so the tail reads as a fixed compact point.
- Per-role rules switch the fill var (`--ownerFlagChipBg`, etc.) — already emitted by strokeMap.

### Section 3 — MESSAGE RIBBON (rewritten, ~#content #message + ::before)
Jagged torn two-tone ribbon (the SVG was white-edge + black-fill; replicate in CSS):
```
.theme-phantom ... #message {
  background: var(--p5-white);                 /* white jagged edge layer */
  color: var(--phantom-ink, var(--p5-white));
  padding: 18px 20px;
  clip-path: polygon( <torn outline ~12 pts> );
}
.theme-phantom ... #message::before {
  content:''; position:absolute; inset: 3px; z-index:0;
  background: var(--p5-black);                 /* black inner fill, text sits white */
  clip-path: <same polygon inset>;
}
```
- `#message` text needs `position: relative; z-index: 1` to sit above the `::before` fill.
- Keep `width: fit-content; max-width: var(--chat-max-width)` (canonical stretch pattern from crayon/ink-sticker).
